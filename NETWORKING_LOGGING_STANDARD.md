# Networking Logging Standard

## Contacts
One row per person. Reuse the same contact across future applications rather than creating duplicates when identity is clear.

Required fields:
Contact ID, linked Job/Application IDs, company, name, title, function, contact type, priority, connection status, dates, reply state, next follow-up, relationship status, work-authorisation ownership, potential value and notes.

## Touchpoints
One row per discrete event:
- connection request;
- post-accept message;
- email;
- reply;
- call;
- referral;
- follow-up;
- status check.

The summary should capture what was said, not merely “message sent.”

## Plans
One row per action step. Blocked actions must name their dependency. Completed actions require completion evidence.

## Message Library
Templates are starting points. Adapt every message to the role and evidence. Store reusable trigger, audience, message and prohibition.

## Date rules
Use actual event dates. Never backdate. When time is known, record it in Touchpoints.

## Evidence
Add a LinkedIn URL, Gmail thread or other evidence link when available. Missing evidence is allowed when the user explicitly confirms the action; note “user confirmed.”
