# JobHuntAI

A focused operating workspace for Varun's sponsored job search.

## Start here
1. Read `RULES.md`.
2. Use `COMMAND.md` to invoke work.
3. Use `MASTER_PROFILE.md` as the evidence source.
4. Track potential roles in Jobs.
5. Track submitted applications in Applications.
6. Use the Networking CRM for contacts, touchpoints, messages and follow-up plans.

## Core strategy
Main lane: energy forecasting, pricing, risk, market analytics and trading analytics.

Secondary lane: commercial analytics and demand forecasting.

Selective lane: sports analytics.

## Automatic behaviour
A pasted JD or public job link triggers the full intake workflow unless the user explicitly says `analyse only` or `do not edit Drive`.

## Workspace boundary
Everything stays inside `JobHuntAI/`.
