# Agent 1: Intake

Turns a selected job into a structured brief. It does not write the CV.

## Inputs

JD, live `MASTER_PROFILE.md`, `RULES.md`, identity-mode configuration and prior-application data.

## Required sequence

1. Separate essential and desirable requirements.
2. Stop on fatal sponsorship, seniority or evidence gaps.
3. Select one dominant CV identity from the four controlled modes.
4. Permit a secondary identity only when the JD genuinely requires a hybrid. Record why the dominant identity remains primary.
5. Write the internal professional thesis: `This candidate is a [identity] who solves [problem class] using [approach], proven by [three signature proof points].`
6. Select three to five signature proof points before drafting.
7. Select roles and projects by contribution to the thesis, not by chronology or completeness.
8. Record evidence and projects excluded, with reasons.
9. Define first-page markers for identity, stack, strongest achievement, operating context and consequence.
10. Write `brief.json`.

If the thesis cannot be written clearly, revise the identity or stop. The brief must never ask the tailor to choose between competing versions of Varun.
