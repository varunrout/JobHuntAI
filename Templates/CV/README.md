# JobHuntAI CV Visual Templates

## Modern Minimal (`jobhuntai-modern-minimal-v1`)
Clean sans-serif layout with strong section dividers, slightly larger body copy and a straightforward ATS-safe visual hierarchy. Best suited to applied science, data science, analytics engineering, technology, product and modern retail roles.

## Classic Gold (`jobhuntai-classic-gold-v2`)
Editorial serif layout with restrained gold accents, denser evidence presentation and a more distinctive executive feel. Remains the established JobHuntAI format and is well suited to strategy, research, football analytics, consulting and roles where a premium visual identity helps.

## Selection rule
Visual template selection is separate from professional archetype selection. Content, evidence controls, official titles, British English and truthfulness gates remain unchanged regardless of visual template.
